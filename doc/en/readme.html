Network Optimization and Diagnostics

This English and Vietnamese NVDA add-on turns useful parts of a network-optimization batch file into clearly described tasks with visible results and explicit confirmation.

Author: Võ Duy Khánh

Opening the add-on

In NVDA, open the Tools menu and choose “Network Optimization and Diagnostics…”. Start with “Quick Check”; this task only reads information and does not change settings. To use a keyboard shortcut, assign a gesture to “Open Network Optimization and Diagnostics” in NVDA Input Gestures.

Customizing the add-on

Open NVDA > Preferences > Settings, then select “Network Optimization and Diagnostics”. This page lets you enable or disable the DNS assistant, choose Cloudflare, Google Public DNS, and/or Quad9 for testing, and show or hide the Maintenance, Advanced, and Stronger Repair groups. Changing these check boxes only controls which features are shown; it never runs a network command automatically.

You can also open this page using the “Customize add-on” button in the add-on window, or assign a gesture to “Open Network Optimization and Diagnostics settings” in Input Gestures. If the Tools-menu item is hidden, the settings page remains available through Preferences > Settings.

Automatically selecting DNS

The add-on tests each enabled public DNS service — Cloudflare, Google Public DNS, and/or Quad9 — three times. It favors consistent responses before comparing response times, then asks you to choose a network connection and confirm before changing that connection’s IPv4 DNS servers.

Quad9 uses malicious-domain filtering, so it can occasionally block a legitimate website. The add-on reminds you of this when Quad9 is the recommended choice.

Test results show the responsiveness of a DNS server from the current connection. They do not measure total Internet speed and do not guarantee faster downloads. The add-on never changes DNS automatically, does not disable IPv6, and does not modify a VPN unless you explicitly select the VPN connection. Depending on the network, Windows may still use IPv6 DNS or VPN DNS.

Use “Restore Automatic DNS (DHCP)” to remove manually configured DNS servers and use the DNS supplied by your router or Internet provider again. This operation only restores DNS to DHCP; it does not change the IP address or gateway.

Saving results

After a task displays results, use “Copy results” to put them on the clipboard or “Save results…” to write a UTF-8 text file at a location you choose. The add-on never uploads or sends the report automatically.

Other tasks

  • Clear DNS Cache: refreshes temporary DNS records.
  • Clear ARP Cache: use only for local-network problems; it can briefly slow down LAN connectivity.
  • Set TCP Auto-Tuning to Normal: restores Windows TCP Auto-Tuning to Normal; it does not guarantee faster Internet access.
  • Reset WinHTTP Proxy: do not use this if your workplace or school requires a proxy.
  • Reset Winsock: use only when necessary; VPN or security software may be affected, and Windows must be restarted.

Safety

Every task that changes the system displays a warning and requests Windows administrator permission. The add-on does not run automatically during installation or when NVDA starts. It has no free-form command box; administrator-level code only uses a fixed list of operations and Windows PowerShell components already included with Windows. The add-on does not automatically reset the firewall, release or renew IP addresses, or use TCP Chimney because that feature is obsolete. The DNS report retains the measurement from before the change and reads the DNS configuration again after it is applied.

Troubleshooting

If no active connection is available to select, open “Windows network settings” from the add-on window and check Wi-Fi or Ethernet first. If you are controlling the computer remotely, do not use stronger network-reset tasks because they can disconnect the remote session.
